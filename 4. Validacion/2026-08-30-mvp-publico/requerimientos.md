# Requerimientos: MVP público

## Alcance
Implementar la primera fase del roadmap para que un visitante anónimo pueda ver platos, armar un carrito y realizar un pedido básico.

## Decisiones
- Usar Next.js App Router con TypeScript para el frontend y API.
- Usar Prisma con SQLite para persistencia.
- Usar Tailwind CSS para estilos.
- Usar React Context o estado local para el carrito en esta fase.
- No implementar autenticación ni panel de administración; se aborda en fases posteriores.

## Contexto
- Misión: conectar clientes con restaurantes de forma simple y confiable.
- Audiencia: desarrolladores de Latinoamérica y estudiantes de Spec-Driven Development.
