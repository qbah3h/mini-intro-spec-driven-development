# Tech Stack

El proyecto utiliza un stack popular, confiable y basado en TypeScript.

## Core

- **Next.js** (App Router): framework full-stack de React con soporte nativo para TypeScript.
- **TypeScript**: tipado estático para todo el código del proyecto.
- **Prisma**: ORM para modelar la base de datos y consultarla de forma segura.

## Base de datos

- **SQLite**: base de datos ligera, sin servidor y fácil de configurar para el proyecto.

## Frontend

- **React**: componentes interactivos.
- **Tailwind CSS**: estilos utilitarios para un diseño ágil y consistente.

## Runtime y despliegue

- **Node.js**.
- Navegadores modernos (Chrome, Firefox, Safari, Edge).
